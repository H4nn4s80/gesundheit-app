Einstellungen

Privater Zugang

Abmelden entfernt den PIN-verschlüsselten Schlüssel von diesem Gerät. Das verschlüsselte Offline-Paket bleibt erhalten. Ein vergessenes Passwort kann hier nicht zurückgesetzt werden.

Kurzbefehle

In Kurzbefehle: „URL“ hinzufügen, dann „URLs öffnen“.

Öffnet eine kompakte Ansicht im Browser. Erst nach PIN/Face ID werden Werte lokal entschlüsselt. Kein echtes iOS-Startbildschirm-Widget und kein öffentlicher JSON-Endpunkt. „Inhalte von URL abrufen“ liefert keine Gesundheitswerte.

Daten & App

Neue Daten werden online geladen, offline wird der letzte verschlüsselte Stand verwendet. Bei einem neuen Passwort musst du erneut entsperren.

Face ID

Mit Face ID entsperren

Face ID nutzt einen Passkey dieses Geräts. Der Datenschlüssel wird damit verschlüsselt, genau wie mit dem PIN. Der PIN bleibt immer als Alternative.
